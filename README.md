# Bertopia

Bertopia is a study app for Android, iOS and macOS built on Anki-compatible packs: trivia packs like Flags and Capitals, and programming packs for software engineering interview practice. Packs come bundled, from the Bertopia store, from Anki imports or from the built-in editor. Progress stays on the device.

- Testing: `docs/testing.md`
